About me

Building things that work,
and look good doing it.

I'm a full-stack web programmer at RSAMI, a Philippine appliance retail company, where I design and build the internal tools that keep operations running — from reporting dashboards to compliance systems.

My work spans every layer: SQL stored procedures and ADO.NET on the data side, C# controllers and Razor views in ASP.NET MVC for the application layer, and Bootstrap with jQuery on the front end. I care about both correctness and craft — the logic has to be right, and the interface has to be clear.

Outside of work, I'm interested in game development and exploring how interactive experiences are designed from the ground up.
